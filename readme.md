# 📖Sistema de Gerenciamento de Biblioteca📖

    Este é meu primeiro projeto desenvolvido em Java.

    O projeto consiste em um sistema simples de gerenciamento de uma biblioteca, feito para praticar os conceitos básicos de Java e Programação Orientada a Objetos.


## 🖥️O que o programa faz:

### O sistema permite:

- Livros:
    Cadastrar livros;
    Listar livros;
    Pesquisar livros pelo título;
    Alterar livros;
    Remover livros;
    Verificar se um livro está disponível.
- Usuários:
    Cadastrar usuários;
    Listar usuários;
    Pesquisar usuários pelo ID;
    Alterar usuários;
    Remover usuários.
- Empréstimos:
    Realizar empréstimos;
    Registrar devoluções;
    Listar empréstimos;
    Listar empréstimos ativos;
    Verificar com qual usuário um livro está;
    Verificar quais livros um usuário possui.

## 🔨Estrutura do projeto:
    
    src/
    ├── Main.java
    ├── Biblioteca.java
    ├── Livro.java
    ├── Usuario.java
    └── Emprestimo.java
    
### Classes:
- Main.java
    É onde o programa é executado e onde ficam os menus para interação com o usuário.
- Biblioteca.java-
    É responsável por gerenciar os livros, usuários e empréstimos.
- Livro.java
    Representa os livros cadastrados na biblioteca.
- Usuario.java
    Representa os usuários da biblioteca.
- Emprestimo.java
    Representa os empréstimos realizados, relacionando um livro a um usuário.

#

## 👨‍💻Como executar
    Para executar o projeto, é necessário ter o Java instalado.
    Depois, basta abrir o projeto em uma IDE, como VS Code, IntelliJ IDEA ou Eclipse, e executar o arquivo Main.java.
